# Phase 6 code progress

19 October 2026. Code changes only; no image build or deployment was performed in this pass.

The active FastAPI/SQLite legacy path now has configurable bounded admission ceilings, a real ASGI multipart-to-native-digital-PDF integration test, and an aggregate GPU FastAPI load harness that can retain one API and two workers over sequential batches. The quality gate checks owner-approved thresholds against independently reviewed scanned-PDF labels, association counts, GPU FastAPI evidence, latency, throughput, retries, and resource peaks. It fails closed on missing evidence and requires at least five reviewed scans and 100 GPU jobs for p99. The gate does not certify image security or operational configuration. [The evidence runbook](docs/runbooks/phase06-release-evidence.md) and an intentionally incomplete policy example specify what the reviewer and owner must supply.

The new [code-quality workflow](.github/workflows/code-quality.yml) specifies lock/advisory, high-confidence secret-pattern, syntax, and CPU-suite checks on changes. It contains no image build or deployment step. The old Azure deployment script is disabled because it used registry admin credentials and lacked the required durable API/worker topology. This checkout has no Git metadata or configured remote, so a hosted CI run has not been observed. The local dependency lock check passed offline; the online advisory audit could not finish in the restricted network environment and was stopped. The full local suite passed: 57 tests. Python syntax compilation passed. The GPU image and runtime were deliberately not built in this pass.

Release acceptance remains open for independent ground truth and association review, owner thresholds, production-representative GPU soak and serialization measurements, GPU image/container offline smoke, image scan and SBOM, independent model publisher provenance, backup encryption/restore, external alert delivery, ingress/TLS, and migration/rollback validation on a target host. The previously run local three-scan FastAPI GPU test is useful functional evidence but not the 100-job release soak. Callbacks, Temporal, and LangGraph remain outside the supported production path.
